## 7.1 设计原则汇总(本系列提炼)

| # | 原则 | 体现 |
|---|---|---|
| 1 | **失联不是死亡** | 三态词表无同义词;普查"查不到 ≠ 没有";部署"silence 不猜零" |
| 2 | **失败方向偏向不动作** | SFTP 绝不换路重试;反降级只拒"可证明更新";无围栏的 kill 不如没有 |
| 3 | **错误的出生地就是语义** | CONNECTION_LOST/DISPOSED 同处铸造;exit 42 终态错误跳过退避 |
| 4 | **迟到者不能破坏新世界** | attempt symbol、connection generation、providerEpoch 三层 fencing |
| 5 | **指数退避不是万能的** | flap 上限从 relay grace 倒算;"重连失败"永不由 flap 触发 |
| 6 | **版本混布是常态** | 协议窗口而非版本对等;opcode 三策略(可忽略/需协商/让号);COMPAT 必须有日落 |
| 7 | **证明不存在需要穷举证据源** | pane 退休要"所有可能的 relay 都问过";普查只有"查到空"才算数 |
